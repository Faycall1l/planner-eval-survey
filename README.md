# Multi-Agent Planning Evaluation Corpus

A searchable web interface for the corpus of 128 LLM-based multi-agent planning systems from the survey "A Survey of Evaluation Methodologies for LLM-Based Multi-Agent Planning Systems" (NAACL 2027).

## Features

- **Search**: Full-text search across paper names, benchmarks, and findings
- **Filter**: Filter by evaluation class, year, and venue type
- **Sort**: Sort by name, class, year, or venue
- **Detail View**: Click any paper to see full protocol codes and key findings
- **Statistics**: Summary statistics for the corpus

## Data

The corpus contains 128 papers from 2023-2026, coded for:
- Evaluation class (6 classes)
- 14 protocol and metric items
- Organization and single-agent comparison outcomes
- Benchmarks and cost definitions
